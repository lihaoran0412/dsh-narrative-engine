# 审阅流程

本文件规定深度审阅 reader 智能体的设计。reader 是独立智能体，与主写作 agent 分离，负责深度诊断。

## 核心要求：reader 必须加载 18+ 技能

**"18+ 技能"即本 preset 自带的 `adult-tension-narrative` 技能**（位于 preset 的 `skills/adult-tension-narrative/`，即 `~/.dsh/.agent-presets/narrative-engine/skills/adult-tension-narrative/`，`~` 为用户主目录，随安装环境自动解析）。**reader 智能体必须加载并遵守该技能**，且**该技能不得干扰审阅流程**：

- 主 agent 写出的章节可能含亲密内容（游玩中已发生且已同意）
- 若 reader 被通用安全策略过滤，它会把 18+ 段落误判为"违规"要求删减，**破坏忠于游玩过程的约束**
- 因此 reader 与主 agent 使用**同一套 `adult-tension-narrative` 安全不变量**：能识别"合法亲密内容"（18+、已同意、`safety_state: running`）与"违规内容"（未成年/未同意/paused 升级）的区别
- **重点：reader 必须能完整读取并评审该技能中"突破 18+ 场景"的部分**（即技能「性行为场景写法（硬约束）」所允许的直白/粗暴/露骨/过程可见的亲密描写），**不能被该技能的安全机制干扰审阅流程**——技能的安全不变量用于**判定合法性**（18+/同意/边界），**不用于删减或回避**合法亲密内容的评审。reader 依据技能判定"这段亲密是否合法"，合法则照常评审其文笔/连续性/忠实度，不因它是 18+ 内容而拒绝评审或要求删减。

## 审阅维度（11 维 60+ 细项）

reader 对照**章纲 / 设定 / 前文**逐条诊断：

| 维度 | 检查内容 |
|---|---|
| 1. 章纲符合度 | 本章是否实现章纲要点，有无偏离 |
| 2. 世界观一致性 | 是否违反 world_bible 设定 |
| 3. 角色一致性 | 性格/称呼/口癖/决策轴是否与角色卡一致 |
| 4. 关系一致性 | 关系变化是否符合游玩记录与关系图 |
| 5. 时间线一致性 | 事件先后、时钟是否与 timeline 冲突 |
| 6. 硬事实忠实度 | 是否忠于游玩记录（硬事实层不可改） |
| 7. 润色层质量 | 补写的内心戏/场景/动作描写是否自然、不越权、不省略 |
| 8. 18+ 合规 | 亲密内容是否"已发生且已同意"、18+、safety_state |
| 9. 文笔与节奏 | 描写质量、张力、可读性、**字数是否达标**（低于档位下限判为问题） |
| 10. 连续性 | 与前文衔接、伏笔回收 |
| 11. 风格一致性 | 是否仿照 style.md 原小说文风（若玩家选择保留原样） |
| 12. 角色卡完整性 | 本章所有出场角色是否都有角色卡（缺失判为问题） |

## 审阅流程

```
① 全部章节写完后，统一触发所有章节的 reader 审阅（每章一个 reader，可并行启动）
② reader 注入：本章正文 + 章纲 + 相关角色卡切片 + 前章摘要 + 世界常量 + 游玩硬事实切片 + style.md 风格要点
③ reader 输出：维度诊断 + 问题清单（逐条：位置/问题/建议）
④ 主 agent 集中收集所有 reader 结果，一次性列出全部问题清单
⑤ 按问题类型批量修复（重写/微调）→ 对修复过的章节再次审阅直到通过
⑥ 通过后落盘为终稿
```

## 审阅触发时机

- **批量审阅**（默认）：全部章节写完后统一审阅，集中收集结果，按类型批量修复（防死循环）
- **每 N 章审阅**（玩家可选）：N 章后一次性诊断
- **终稿审阅**：全书完成后整体过一遍

> 审阅流程遵循「写作流程.md」的**禁止重复思考硬约束**：不要 busy-poll reader 状态，收到结果后先列完整修复计划再动手。

## 实现方式

reader 智能体通过 DSH 子代理机制实现，与主 agent 共享同一 18+ 技能与安全不变量。

### reader 用 one-shot 模式（默认）+ 允许追问

- **默认用 one-shot 模式**（`subagent_reader` 工具）：reader 是一次性审阅任务，结算后自动释放，不累积子代理。
- **允许追问**：若某章审阅结果需要 reader 进一步澄清，可对**少量关键章节**用可继续模式（`subagent` 工具）启动，审阅后可用 `send_message` 追问。
- **规则**：绝大多数章节用 one-shot；只有确实需要追问的章节才用可继续模式。审阅完成后不要保留无用的可继续 reader。

### reader 的 prompt 必须明确

1. 加载 `adult-tension-narrative` 技能，能评审 18+ 内容，不因 18+ 而删减。
2. 核对**出场角色 vs 角色卡**是否齐全（维度 12）。
3. 检查**字数是否达标**（维度 9）。
4. 输出结构化问题清单（位置/问题/建议）。
