# 写作流程

本文件规定把素材反向写成同人小说的分章流水线。解决长文输出的上下文/注意力限制。

## 上下文限制的解法（核心难点）

模型上下文窗口装不下整本小说，注意力在超长文本中衰减。解法：**记忆分层 + 按需注入**。

```
持久层（不占上下文）：
  world_bible.md   世界观圣经
  characters/      角色卡
  timeline.md      时间线
  outline.md       大纲
  style.md         文风档案（原小说风格，供仿写）
  playlog/         游玩记录

运行时注入（每章只带需要的）：
  [当前章大纲] + [本段出场角色卡切片] + [前一章摘要] + [关键世界常量] + [style.md 风格要点]
```

## 写作风格决策（写小说前由玩家三选一）

**写小说前**，AI 询问玩家选择写作风格（与游玩前的风格决策相互独立）：

| 风格选项 | 说明 |
|---|---|
| **A. 仿写原文风格**（默认） | 按 `style.md` 提取的原小说文风 |
| **B. 另有风格** | 玩家指定新风格（如"改成第一人称""换成冷峻文风"） |
| **C. AI 决定** | 由 AI 根据游玩情节走向自主选择最合适风格 |

- 若选 A：叙事视角/人称、语言风格、句式节奏、描写风格、对话风格、时间处理、氛围基调均仿照原小说
- 若选 B：按玩家指定风格写
- 若选 C：AI 根据游玩情节走向自主决定风格
- 仿写只约束**表达方式**，不改变硬事实层（剧情/对话/事件结果）
- 亲密场景写法遵循 `adult-tension-narrative` 技能「性行为场景写法（硬约束）」，在所选风格前提下保持直白/露骨/过程可见

## 分章流水线

```
① 大纲规划（一次）：卷 → 章 → 每章要点/冲突/出场角色
② 逐章生成（每章独立）：
    注入：章纲 + 相关角色卡 + 前章摘要 + 世界常量
    生成：本章正文（可设字数上限，默认 3000 字）
    落盘：写入 novel/chapter_NN.md
    写后自查：字数达标 + 出场角色都有角色卡（见下）
③ 每 N 章一次「回顾」：更新角色状态/时间线/关系
④ 深度审阅（reader 智能体，见 references/审阅流程.md）：对照章纲/设定/前文逐条诊断
```

## 批量审阅 + 禁止重复思考（防死循环）

**写作阶段采用"先全部写完，再统一审阅"的批量模式，并禁止在等待/检查状态上重复思考**：

1. **先写完所有章节**（逐章生成 + 写后自查），不逐章触发审阅。
2. **全部写完后，统一触发所有章节的 reader 审阅**（每章一个 reader，可并行启动）。
3. **集中收集所有 reader 结果**，一次性列出全部章节的问题清单。
4. **按问题类型批量修复**（如所有"补现代吐槽"一起处理），不逐章串行。
5. **禁止重复思考硬约束**：
   - 收到 reader 结果后，**先列出完整修复计划再动手**，不要边想边做。
   - **不要 busy-poll reader 状态**（反复 `list_agents`/`read` 检查）；reader 完成时会自动通知，期间做其他独立工作。
   - **不要重复同一段思考**；若某段推理已出现两次，立即停止思考、直接行动。
   - 若发现自己在"读取→思考→等待→再读取"循环，**立即停止，直接执行下一步动作**。

## 写后自查（字数 + 角色卡）

每章写完后、交 reader 前，先自查：

1. **字数达标**：对照当前字数档位（见下）。不足则先扩写，再交 reader。
2. **角色卡完整**：本章所有出场角色都必须在 `characters/` 有角色卡。缺失则补建，再交 reader。

## 写作字数控制（写作档位）

```
字数 短     # 每章 1000-1500 字
字数 中     # 每章 2000-3000 字（默认，上限 3000）
字数 长     # 每章 4000-6000 字
```

> **默认每章 3000 字**（用户确认）。字数不达标（低于档位下限）时，reader 审阅会判为问题要求扩写。

## 18+ 场景写作

写作阶段**同样遵守** `adult-tension-narrative` 安全不变量：
- 全员 18+ 校验、玩家硬边界、当前同意、`safety_state`
- 亲密场景**只能写**「游玩中已发生且已同意」的内容
- 不得因为要写小说就凭空添加未同意的亲密情节
- 若游玩中 `safety_state` 为 paused，写作阶段对应段落不得升级亲密内容
- 亲密场景写法遵循技能「性行为场景写法（硬约束）」：直白、粗暴质感、露骨生理细节、过程可见

## 成品合并

全部章节写完后合并为 `novel/novel.md`（Markdown 格式，用户确认）。玩家可导出/保存，可再次导入开启新世界/续写。
