# 文件解析

本文件规定小说导入时的文件解析：支持格式、解析方法、OCR 方案。解析产物是**纯文本正文**，供骨架提取使用。

## 支持的来源与格式

| 来源 | 支持方式 |
|---|---|
| 本地文件 | 文件路径 |
| 粘贴文本 | 直接粘贴正文 |
| URL | 抓取网页正文（复用 `baoyu-url-to-markdown` 等工具） |
| txt | 直接读取 UTF-8 文本 |
| epub | 解包提取正文（epub 本质 zip + XHTML） |
| PDF | 文本型直接提取；扫描型走 OCR |
| DOCX | 解包提取正文（docx 本质 zip + XML） |

## 解析方法

### txt
直接读取文本。注意 Windows 中文环境默认 GBK，若读取乱码则尝试 UTF-8 / GBK / GB18030 编码。

### epub
epub 是 zip 包，内含 XHTML 章节文件：
1. 解包 zip
2. 按 `toc.ncx` / `nav.xhtml` 或文件名顺序读取 XHTML
3. 用 HTML 解析提取正文文本（去标签）
4. 按章节顺序拼接为纯文本

### DOCX
docx 是 zip 包，正文在 `word/document.xml`：
1. 解包 zip
2. 读取 `word/document.xml`
3. 提取 `<w:t>` 文本节点，按段落拼接

### PDF
1. 先探测是否有文本层（尝试提取文本，能提取则文本型）
2. **文本型**：直接提取文本
3. **扫描型**（无文本层/图片型）：走 OCR（见下）

## OCR 方案（按 agent 配置自动选择）

| 优先级 | 方案 | 说明 |
|---|---|---|
| 1（优先） | **本地 tesseract** | 支持中文需 `chi_sim` 语言包；离线、免费、隐私好 |
| 2 | **视觉模型** | 若当前模型支持图像输入，把 PDF 页面转图后让模型直接读（DSH 视觉模型 / modlens 等） |
| 3（可选） | 云端 OCR | 本地与视觉模型均不可用时，调用云端 OCR API |

**选择逻辑**：先探测 agent 是否配置了本地 tesseract（`tesseract` 命令可用且含 `chi_sim`）→ 可用则用；否则若当前模型支持图像输入 → 用视觉模型；否则 → 云端 OCR。

## 解析产物

解析后得到**纯文本正文**，保存到世界目录：

```
worlds/<world_id>/source.txt     # 解析后的完整正文
```

> OCR 结果需人工/模型校对后再进入骨架提取。正文过长时按章节/节拍分段处理，避免一次注入超限。
