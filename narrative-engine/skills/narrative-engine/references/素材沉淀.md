# 素材沉淀

本文件规定把游玩记录转写为可写小说的结构化素材。游玩记录在 `playlog/`，本阶段读取后转写为素材。

## 读取最终有效版本

写作前，AI 读取 `playlog/` 中所有 `status: committed` 的回合（跳过 superseded），按时间顺序重建游玩全过程。

## 转写产物

```
剧情大纲（outline.md 更新）   把游玩回合归并成剧情节拍（卷-章-节）
时间线（timeline.md 更新）    合并游玩时钟，标注因果链
角色互动记录                  对话/关系变化/谁对谁做了什么
对话素材                      可直接引用/润色的对话
```

## 硬事实层 vs 润色层（约束 2）

| 层 | 内容 | 可否补写 |
|---|---|---|
| **硬事实层** | 剧情走向、对话内容、事件结果、关系变化、谁对谁做了什么 | **不可改**，忠于游玩记录 |
| **润色层** | NPC 内心戏、环境氛围、场景细节、动作描写 | **可补写**，游玩时没展示的可补 |

**关键约束**：
- 补写不得改变硬事实；尤其不得凭空添加「未在游玩中发生且未同意」的亲密内容。
- **润色层的动作描写必须比游玩过程更丰富、不能省略**（用户确认）：游玩时可能只写了"两人交合"，写作时必须展开为完整、连续、有细节的动作描写，不因游玩记录简略而省略动作过程。动作描写在忠于硬事实的前提下充分扩展，让小说比游玩记录更丰满。

## 素材标记

转写产物需标记哪些是硬事实层（不可改）、哪些是润色层（可补写），供写作阶段遵守：

```
素材文件内用注释/标记区分：
  [硬事实] 剧情走向、对话、事件结果、关系变化
  [润色]   NPC 内心戏、环境氛围、场景细节、动作描写
```
