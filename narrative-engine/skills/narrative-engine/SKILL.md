# 沉浸叙事双向创作引擎

本技能是 `adult-tension-narrative` 的**扩展**，负责双向创作闭环的四个阶段：

```
① 导入：小说 → 世界（骨架提取/补全/切入点）
② 游玩：复用 adult-tension-narrative 引擎（本技能不重复游玩规则）
③ 沉淀：游玩 → 素材（硬事实层/润色层）
④ 写作：素材 → 小说（分章流水线 + 深度审阅 reader）
```

**游玩阶段完全复用 `adult-tension-narrative` 技能**（18+ 校验、硬边界、同意、safety_state、暂停/安全词、玩家叙事主权、NPC 决策、时间/Tier 追算、v3 存档）。本技能只负责导入、沉淀、写作三阶段，以及游玩时的回合自动落盘。

## 安全不变量（贯穿全流程，最高优先）

与 `adult-tension-narrative` 完全一致，所有阶段（导入/游玩/沉淀/写作）统一遵守：

1. **18+ 校验**：所有参与角色必须明确年满 18 岁；导入时若小说角色年龄缺失或含混，停止亲密内容并补齐。
2. **玩家硬边界**：`本局不碰 X` 维护；写作阶段同样尊重，不写边界内内容。
3. **当前同意**：亲密内容仅在 `safety_state: running` 时写；paused 时停止亲密升级。
4. **`暂停`/`安全词`**：任何阶段随时可用。
5. **写作不越权**：小说只能写「游玩中已发生且已同意」的亲密内容，不得因创作需要凭空添加未同意情节。

## 单世界目录结构

一个会话绑定一个世界目录（单世界模式）：

```
worlds/<world_id>/
  world_bible.md      世界观圣经：常量/规则/力量体系/地理/社会规则
  characters/         角色卡（每角色一卡 <char_id>.md）
  timeline.md         时间线：事件/因果链
  outline.md          大纲：卷-章-节-要点
  style.md            文风档案：原小说风格（供写作仿写）
  playlog/            游玩原始记录（回合自动落盘）
    turn_001.yaml
  novel/              写作产出
    chapter_001.md
    novel.md          合并后的完整小说
  saves/              技能 v3 存档（复用 manage_saves.py）
    slots/main/state.yaml
  state.json          引擎状态：当前阶段/字数档位/安全状态/节拍点
```

## 命令总览

### 导入阶段
| 命令 | 行为 |
|---|---|
| `导入 <路径/URL>` | 开始导入（txt/epub/PDF/DOCX/URL/粘贴文本） |
| `确认骨架` | 确认 AI 提取的骨架 |
| `补全 <程度>` | 设置补全程度（轻/中/重） |
| `保留 <项>` | 某项保留原样不补全 |
| `微调 <项>=<值>` | 逐项微调 |
| `节拍点` | 查看节拍点列表（切入点导航） |
| `切入 <编号>` | 从节拍点 N 开始 |
| `切入 <描述>` | 按场景描述定位切入点 |
| `续写` | 从小说结尾之后开始 |
| `粒度 <粗/细>` | 调整节拍点切分粒度 |
| `开始游玩` | 生成 v3 存档并进入游玩 |

### 游玩阶段（复用 adult-tension-narrative 命令 + 新增）
| 命令 | 行为 |
|---|---|
| `继续`/`快进`/`存档`/`载入`/`状态` 等 | 复用原技能命令 |
| `字数 <短/中/长/超长>` | 游玩输出字数档位 |
| `本局不碰 X`/`暂停`/`安全词` | 复用原技能安全命令 |

### 写作阶段
| 命令 | 行为 |
|---|---|
| `写小说` | 从素材开始写作 |
| `大纲` | 生成/查看小说大纲 |
| `写下一章` | 生成下一章 |
| `重写第 N 章` | 重写某章 |
| `审阅` | 触发 reader 深度审阅（12 维，批量审阅） |
| `审阅 <每章/每N章/终稿>` | 设置审阅触发时机 |
| `风格 <仿写原文/另有风格/AI决定>` | 设置风格（游玩前和写小说前各询问一次，三选一） |
| `字数 <短/中/长>` | 写作字数档位 |
| `导出小说` | 输出完整小说 |

## 阶段流转

```
导入完成 → 开始游玩（进入 adult-tension-narrative 引擎）
游玩中每回合自动落盘 playlog/
游玩结束 → 写小说（素材沉淀 → 分章写作 → 审阅 → 成品）
```

本文件是执行主控，领域规则按职责拆分在 `references/` 下。玩家可见的只有正文、状态说明、节拍点列表和导出的小说，不暴露字段名、台账或内部机制。
